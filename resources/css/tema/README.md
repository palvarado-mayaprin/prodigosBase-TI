# resources/css/tema

Sistema visual con prefijo `adm-`, trasladado del lenguaje visual aprobado (Etapa 6):

- `tokens.css`: único lugar con colores (tokens semánticos personalizables).
- `componentes.css`: estructura, medidas, tipografía y componentes; sin colores literales.

Cambiar la paleta solo modifica `tokens.css`; nunca la estructura ni las medidas.
